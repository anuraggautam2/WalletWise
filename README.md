# WalletWise 🪙

> **Student Expense Tracker** — A modern, dark-themed fintech web application designed specifically for students to take control of their finances and build better money habits.

---

## 🌟 Overview

WalletWise is an intuitive, student-centric expense tracking platform inspired by modern fintech leaders like Linear and Stripe. Designed to replace cluttered spreadsheets and complicated accounting software, WalletWise gives students the exact tools they need to track daily expenses, stay within budget, and understand their spending habits with clarity.

---

## ✨ Features

- **⚡ Fast Expense Tracking:** Log campus expenses, food, and course materials in seconds.
- **🎯 Budget Management:** Set monthly allowances with visual pacing meters to avoid running out before month-end.
- **📊 Spending Analytics:** Understand spending patterns, weekly rhythms, and category allocations.
- **🔍 Transaction History:** Searchable, category-filtered activity feed.
- **📑 Monthly Statements:** Clear snapshots showing total outflows, savings, and top spending areas.
- **🏦 Savings Awareness:** Milestone tracking for tech upgrades, semester funds, and savings goals.
- **🎨 Premium Dark UI:** Crafted with a dark fintech aesthetic (`#080D1A`), subtle ambient radial lighting, translucent cards, and responsive layouts across mobile, tablet, and desktop.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/singh81nikhil-eng/WalletWise.git

# Navigate into project directory
cd WalletWise

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Building for Production

```bash
npm run build
```
